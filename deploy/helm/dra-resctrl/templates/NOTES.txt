Cache Partition DRA Driver installed.

Nodes must have the label:
  cache-partition.fabiendupont.io/resctrl-cat=true

To label nodes manually:
  kubectl label node <name> cache-partition.fabiendupont.io/resctrl-cat=true

Or install the NodeFeatureRule for auto-detection (requires NFD):
  kubectl apply -f deployments/node-feature-rule.yaml

Verify the driver is running:
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/name={{ include "dra-cache-partition.name" . }}

Verify ResourceSlice is published:
  kubectl get resourceslices -o json | jq '.items[] | select(.spec.driver == "{{ .Values.driverName }}")'

Create a claim:
  kubectl apply -f deployments/examples/claim.yaml

Refer to the README for full usage instructions.
